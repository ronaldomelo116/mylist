# 📝 Minha Lista de Tarefas (MyList)

Uma aplicação web simples, leve e intuitiva para organizar suas tarefas diárias e afazeres em tempo real.

---

## 🚀 Sobre o Projeto

O **Minha Lista** é um projeto desenvolvido para facilitar o gerenciamento de afazeres do dia a dia. Com uma interface limpa, moderna e responsiva, permite criar listas personalizadas, alterar o título da lista dinamicamente e adicionar/remover tarefas de maneira ágil.

---

## ✨ Funcionalidades

- 🏷️ **Título Dinâmico**: Permite personalizar o nome da lista com atualização instantânea enquanto você digita.
- ➕ **Adição Rápida de Tarefas**: Adicione novos itens clicando no botão "Adicionar" ou pressionando a tecla <kbd>Enter</kbd>.
- ❌ **Remoção Individual**: Exclua itens concluídos ou indesejados através de um botão dedicado com feedback visual.
- 🎯 **Foco Automático**: O campo de texto é limpo e ganha foco automaticamente após a inserção de um item, acelerando o fluxo de digitação.
- ⚠️ **Validação de Entrada**: Verificação para evitar a inserção de itens vazios.
- 📱 **Interface Responsiva**: Design centralizado e adaptável para computadores, tablets e smartphones.
- 🌐 **Otimização SEO & Open Graph**: Configurações prontas para pré-visualização em redes sociais e mensageiros (WhatsApp, Telegram, LinkedIn).

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web puras (*Vanilla*):

- **HTML5**: Marcação semântica e metadados de compartilhamento.
- **CSS3**: Estilização moderna com Flexbox, sombras suaves e microinterações de hover/active.
- **JavaScript (ES6+)**: Manipulação nativa do DOM e captura de eventos.

## 💻 Como Executar o Projeto

Por se tratar de um projeto puramente estático, não é necessária a instalação de dependências ou servidores backend:

1. **Clone ou baixe o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/mylist.git
   ```

2. **Acesse o diretório do projeto:**
   ```bash
   cd mylist
   ```

3. **Abra no navegador:**
   - Dê um duplo clique diretamente no arquivo `index.html`, **ou**
   - Caso utilize o Visual Studio Code, use a extensão **Live Server** (clique com o botão direito em `index.html` > *Open with Live Server*).
